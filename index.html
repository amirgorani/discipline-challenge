اتصال به دیتابیس Supabase

این برنامه بدون سرور اختصاصی کار می‌کند: فرانت‌اند روی GitHub Pages و داده‌ها در دیتابیس Supabase شما. فقط کلید عمومی anon استفاده می‌شود (هرگز service_role را اینجا وارد نکنید).

  1. در supabase.com یک پروژه رایگان بسازید.
  2. در داشبورد Supabase وارد SQL Editor شوید و محتوای فایل supabase/schema.sql این پروژه را اجرا کنید (جدول‌ها + امنیت RLS ساخته می‌شود).
  3. برای تست ساده‌تر: Authentication → Sign ups گزینه Confirm email را خاموش کنید.
  4. از بخش Settings → API مقادیر Project URL و anon public key را کپی و زیر وارد کنید.

        امنیت و ذخیره‌سازی

        احراز هویت و دیتابیس با Supabase است. فرانت‌اند فقط از کلید عمومی anon استفاده می‌کند و سیاست‌های Row Level Security تضمین می‌کنند هر کاربر فقط به چالش‌ها، وظایف، ثبت‌ها و امتیازهای خودش دسترسی دارد. کلید service_role هیچ‌وقت در کد فرانت‌اند قرار نمی‌گیرد.
